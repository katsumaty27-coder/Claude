# エリア検討ログ

## 前提条件

- 職場: 麻布台ヒルズ(港区)
- 通勤手段: 車(高速道路利用可)
- 到着時刻の想定: 平日朝8:30頃
- 許容通勤時間: 20〜25分圏内
- 備考: 朝の通勤ラッシュは麻布台方面への流入方向と重なるため、オフピーク時の所要時間より実際は伸びる前提で見ておく。首都高は都心環状線・霞が関出口・飯倉ランプが起点になり、そこから2号目黒線・3号渋谷線・都心環状線経由でアクセスできる範囲が候補になる。
